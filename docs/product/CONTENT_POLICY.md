# Content policy

Every character labelled `MATURE` enters a human moderation queue before public discovery.
Editing a published Mature character reopens review. The system risk signal is informational and
cannot impose an automatic account sanction; only an authorized moderator can approve, hide,
remove or escalate the character.

Запрещены sexual content involving minors, эксплуатация, инструкции к тяжёлому вреду,
незаконный контент, impersonation fraud, targeted harassment, doxxing и malware.

Adult fictional roleplay отделён age gate и backend content labels. Неопределённый возраст
в adult context трактуется консервативно. Пользовательский prompt, lore и character definition
всегда считаются untrusted input и не дают системных полномочий.
