# User flows

1. `/start` → «Открыть» → Telegram `initData` → server validation → local session.
2. Four-step first run: concise intro → explicit policy and optional 18+ mode → optional private
   persona → safe live recommendations → catalog or immediate chat.
3. Character card → character details → persona selection → new conversation.
4. Message → idempotent persist → generation lock → streamed AI response → accounting.
5. Regenerate/edit → alternative branch; previous variant remains accessible.
6. Memory → edit/summarize/regenerate/restore, each action creates a version.
7. Creator → draft autosave → preview chat → moderation → publish.
8. Report → triage → least-privilege review → action → appeal.
9. Credits → one-time Telegram Stars invoice → idempotent ledger grant.
10. Delete account → confirmation → erasure/anonymisation job and counter reconciliation.
