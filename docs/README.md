# Velora knowledge base

Документы в этом каталоге — system of record проекта. Рабочее имя Velora временное до
проверки бренда. Реализация ведётся независимо от RoleMate.

- `product/` — продукт, потоки, монетизация и политики.
- `architecture/` — система, данные, AI, memory, безопасность и эксплуатация.
- `api/` — HTTP/webhook contracts и единая модель ошибок.
- `design/` — самостоятельная visual language и mobile-first UX.
- `operations/` — deploy, backup/restore, incidents, стоимость и owner runbook.
- `testing/` — план, матрица, трассировка всех требований и критерии приёмки.
- `decisions/` — проверяемые архитектурные решения.
- `execution/` — план, задачи, статус, решения и технический долг.

Полное исходное ТЗ хранится во внешнем приложенном brief; его обязательные требования
разложены по этим документам и матрице приёмки.
